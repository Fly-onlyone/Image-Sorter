# Facet

> An identity dimension to sort images by — either `character` or `artist`.

A run's `layout` is a list of facets that decides how the output tree is organised. The
`character` facet groups by who is depicted (driven by [[CCIP]] identity matching in the
[[Identify Phase]]); the `artist` facet groups by who drew it (resolved from metadata sidecars
and reverse-image lookup). Selecting facets lets the same sorted run be expressed as different
folder hierarchies.

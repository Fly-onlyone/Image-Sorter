# Prototype

> A stored [[CCIP]] feature vector representing one character — typically one per outfit.

Prototypes are the reference embeddings the [[Identify Phase]] matches new crops against (see
[[Gallery Prototypes]]). A character usually has several, one per distinct outfit, because the
same character can look very different across costumes. Enrollment — naming a character or
naming a cluster from the [[Residual]] — creates prototypes, which improves recognition on
future runs.
